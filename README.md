## 🤖 自動化腳本說明

這四支腳本可在下一學年度（116學年度）重複使用，自動產製課程計畫文件。

### 環境需求

- Python 3.8 以上
- 執行環境：Windows（路徑使用反斜線）

### 腳本一：`gen_biao3.py` — 產生空白版表3

**用途：** 以空白模板為底，自動填入學校名稱、年級、週次、校訂課程，產出 6 個年級的空白表3。

**執行方式：**
```bash
python gen_biao3.py
```

**輸出：**
```
claude 操作\115表3課程計畫_一年級.docx
claude 操作\115表3課程計畫_二年級.docx
...（共 6 個）
```

**修改設定（腳本開頭）：**
| 變數 | 說明 | 範例 |
|------|------|------|
| `GRADES` | 年級清單與對應的 114 來源檔名 | 視新學年調整 |
| `TPL_DOCX` | 空白表3模板路徑 | `表3.docx` |
| `SRC_DIR` | 114 年度表3來源資料夾 | `114表三表四\` |
| `OUT_DIR` | 輸出資料夾 | `claude 操作\` |

---

### 腳本二：`fill_biao3.py` — 填入各科教學內容

**用途：** 讀取各出版社課程計畫（康軒、南一、翰林、客語、閩南語），自動填入表3各科欄位。

**執行方式：**
```bash
python fill_biao3.py
```

**填入的科目對應：**
| 欄位 | 科目 | 來源 |
|------|------|------|
| col4 | 國語文 | 康軒（KX） |
| col5 | 本土語文 | 客語（1,3,5年）/ 閩南語（2,4,6年） |
| col6 | 英語文 | 康軒（KX） |
| col7 | 數學 | 南一（1~4年）/ 翰林（5~6年） |
| col8 | 社會 / 生活課程 | 康軒（KX） |
| col9 | 自然（3~6年） | 康軒（KX） |
| col10 | 藝術（3~6年） | 康軒（KX） |
| col11 | 綜合（3~6年） | 康軒（KX） |
| col12 | 健體 | 南一（N1） |

> ⚠️ 1~2 年級無自然/藝術/綜合（合科為生活課程），這三欄自動留空。

**修改設定（腳本開頭）：**
| 變數 | 說明 |
|------|------|
| `KX_DIR` | 康軒總表資料夾路徑 |
| `HK_DIR` | 客語資料夾路徑 |
| `N1_DIR` | 南一課程計畫資料夾路徑 |
| `HL_DIR` | 翰林課程計畫資料夾路徑 |
| `GRADES` | `(年級數字, 中文名, 本土語別, 數學來源)` |

---

### 腳本三：`gen_biao4.py` — 產生表4彈性學習課程計畫

**用途：** 以 114 來源表4為底，自動替換學年度與勾選框標籤，產出 115 版表4。

**執行方式：**
```bash
python gen_biao4.py
```

**輸出：**
```
claude 操作\115表4彈性學習課程計畫.docx
```

**替換規則：**
| 原文 | 替換為 | 說明 |
|------|--------|------|
| `114學年度` | `115學年度` | 學年度更新（共 2 處） |
| `安全教育`（勾選框） | `交通安全` | 115版更名（共 50 處） |

**保留不換的例外（課程單元標籤與內容）：**
- `(安全教育)2.This is Me` — 國際教育課 一年級單元名
- `(安全教育)2.Time` — 國際教育課 三年級單元名
- `(安全教育)6.食在足夠` — 國際教育課 五年級單元名

**修改設定（腳本開頭）：**
| 變數 | 說明 |
|------|------|
| `SRC_DOCX` | 114 來源表4路徑 |
| `OUT_DOCX` | 輸出路徑 |
| `EXCEPTIONS` | 不替換的 XML run 清單（單元標籤） |

---

### 腳本四：`audit_biao3.py` — 反查內容是否正確

**用途：** 讀取已產製的 6 個表3，逐欄比對是否含有正確出版社關鍵字，列出 ✅ / ❌ / ⚠️ 報告。

**執行方式：**
```bash
python audit_biao3.py
```

**輸出範例：**
```
【三年級】
  上學期（表1）：
    col4 國語文: ✅ 含「康軒」→ "康軒版國語文三年級上學期..."
    col7 數學:   ✅ 含「南一」→ "南一版數學三年級上學期..."
    col9 自然:   ✅ 含「康軒」→ "康軒版自然科學三年級..."
    ...
反查結果：✅ 72 項正確  ❌ 0 項錯誤  ⚠️ 0 項警告
```

## 🔄 下學年度使用流程

```
1. 取得新學年各出版社課程計畫 DOCX
2. 更新腳本中的路徑與年級設定
3. python gen_biao3.py   → 產生空白版表3（含週次與校訂課程）
4. python fill_biao3.py  → 填入各科教學內容
5. python audit_biao3.py → 確認內容是否符合表2選用版本
6. python gen_biao4.py   → 產生表4彈性學習課程計畫
7. 輸出的 DOCX 即可交給老師使用
```
